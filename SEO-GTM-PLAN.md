# WA Web Utils SEO and Growth Plan

## Goal
Maximize qualified reach for WA Web Utils and the related WA Web utility extension portfolio by capturing high-intent WA Web CRM workflow searches and converting visitors to Chrome Web Store installs.

## Positioning
WA Web Utils is a practical Chrome extension that adds CRM workflows to WA Web in Chrome: follow-ups, templates, scheduling, broadcasts, unsaved-number chat, exports, and deleted-message history.

## Search Clusters
- WA Web CRM: `/use-cases/whatsapp-web-crm.html`
- Chat CRM: `/use-cases/chat-crm.html`
- WA Web bulk sender: `/use-cases/chat-bulk-sender.html`
- WA Web message scheduler: `/use-cases/chat-message-scheduler.html`
- WA Web message templates: `/use-cases/chat-message-templates.html`
- Message unsaved linked chat number: `/use-cases/message-unsaved-chat-number.html`
- Deleted chat messages: `/use-cases/deleted-chat-messages.html`

## Technical SEO
- Canonical URLs on homepage and each use-case page.
- Sitemap at `/sitemap.xml`.
- Robots file at `/robots.txt`.
- Homepage SoftwareApplication schema with live Chrome Web Store install URL.
- FAQ schema on the WA Web CRM cornerstone page.
- Internal links from homepage, footer, and related use-case pages.
- Repeatable IndexNow submission via `npm run seo:indexnow:record`.
