Chat CRM guide

Use lead views to prioritize the right chats.

Lead views organize missed replies, hot contacts, tagged conversations, and scheduled follow-ups into focused queues.

  1. Open WA Web Utils inside the WA Web workspace.
  2. Select Leads from the extension sidebar.
  3. Choose the queue that matches your job: Needs Reply, Hot Leads, or Follow-ups.
  4. Open the chat, add notes or tags, and schedule the next action.

Best for sales teams that need a lightweight Chat CRM without leaving the WA Web workspace.

Templates guide

Use templates for repeat WA Web replies.

Templates keep pricing replies, support answers, onboarding messages, and campaign copy consistent.

  1. Open the Templates option from WA Web Utils.
  2. Select the saved message that matches the customer question.
  3. Review the text before sending.
  4. Use tags or reminders if the reply creates a follow-up task.

Scheduler guide

Schedule follow-ups while the chat is fresh.

Scheduled messages help with callbacks, appointment reminders, renewals, payment nudges, and class updates.

  1. Open the customer chat in the WA Web workspace.
  2. Select Schedule in WA Web Utils.
  3. Write or insert the message template.
  4. Choose the date and time, then save the scheduled action.

Use this with the chat message scheduler guide for follow-up-heavy teams.

Bulk sender guide

Prepare campaigns with checks before sending.

Bulk sending is for legitimate customer communication where audience quality, template copy, readiness, and pacing matter.

  1. Open Bulk from WA Web Utils.
  2. Choose or prepare the recipient list.
  3. Select the approved template and review the message.
  4. Run readiness checks before live sending.

Unsaved-number guide

Start chats from raw phone numbers.

This helps when leads arrive from forms, spreadsheets, ads, CRM exports, or websites before they exist as saved contacts.

  1. Copy the phone number from your lead source.
  2. Open the new-chat option in WA Web Utils.
  3. Confirm country code or local-number behavior.
  4. Open the chat and send the first message.

Learn more in the message an unsaved linked chat number workflow.

Deleted history guide

Review deleted-message history from Settings.

Deleted-message history is sensitive. Use it intentionally, review it locally, and clean records you no longer need.

  1. Enable deleted-message history only when your workflow needs it.
  2. Open WA Web Utils Settings.
  3. Review sender, chat, time, and message context.
  4. Select and delete rows you no longer need.

Read the deleted chat message history page and privacy policy.

Guide FAQ

Feature guide questions.

Are these real screenshots?

They are HTML-rendered product screenshots built from the WA Web Utils UI model, with key options highlighted so the explanation remains clear on desktop and mobile.

Which feature should I start with?

Start with lead views if your team misses replies, templates if the team repeats answers, scheduler if follow-ups slip, and bulk sender if you prepare customer campaigns.

Do these guides replace support?

No. Use the guides for workflow education and the support page for billing, login, manual activation, and troubleshooting.

Is deleted-message history private?

WA Web Utils presents deleted-message history as a local-first feature for Settings review and cleanup after it is enabled.
